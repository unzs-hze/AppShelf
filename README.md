# AppShelf · 本机应用清单

从首页进入应用目录，整理软件的分类、路径和介绍，也可以查看日、周、月前台使用时间。界面使用 HTML/CSS/JavaScript，Python 提供本地接口，PyWebView 将同一套页面放入桌面窗口。

本次调整保留现有界面和技术栈，将接口、应用操作、扫描、校验和存储拆成独立模块。用户清单与程序文件分开保存，扫描与编辑通过统一事务更新数据。

## 运行

本地完整功能面向 **Windows 10/11、Python 3.12 或更新版本**。在项目根目录运行下面的命令。

### 浏览器版

仅需 Python 标准库，无需安装桌面依赖：

```powershell
python server.py
```

打开 <http://127.0.0.1:8931>，默认进入 `home.html` 首页。顶部导航可切换「首页」「应用目录」「使用时间」，原有 `index.html` 继续作为应用目录。可以指定端口：

```powershell
python server.py 8932
```

### 桌面版

```powershell
python -m pip install -r requirements.txt
python main.py
```

桌面入口先绑定本地服务，再打开首页窗口，使用系统分配的空闲端口。桌面版和浏览器版共用页面、应用管理与存储逻辑。

### 首次使用

默认在 `%LOCALAPPDATA%\AppShelf` 创建空清单，然后启动扫描；之后每 30 分钟扫描一次。也可以在页面点击「扫描本机」。扫描完成后，新条目标为「新发现」，可补全介绍、分类并确认收录。

仓库中的 `data/apps.json` 是保留的旧清单快照，**不会自动导入新用户数据目录**。因此新电脑不会混入快照原作者的软件记录。

扫描读取 Windows 注册表卸载项、桌面与开始菜单快捷方式，并在有限软件目录内寻找已知便携副本。范围以外的便携软件和部分系统内置应用仍可能无法自动发现。

## 先查看原有清单

把旧快照导入独立的本地目录，并关闭自动扫描，便于核对界面和编辑流程：

```powershell
python server.py --data-dir local-data --import data/apps.json --no-scan
```

导入只允许写入**空清单**，不会修改导入源文件。再次启动同一份清单时，去掉 `--import`：

```powershell
python server.py --data-dir local-data --no-scan
```

`--no-scan` 只关闭启动时及定时扫描，页面的手动扫描仍可使用，使用时间统计仍会运行。桌面入口也接受 `--data-dir`、`--import` 和 `--no-scan`。`--no-background` 本次不启动后台进程，已有独立后台不受影响；`--disable-background --data-dir <目录>` 停止该目录的后台记录并取消登录自启，不打开窗口。

## 数据保存与恢复

数据目录的选择顺序为：`--data-dir` 参数、`APPSHELF_DATA_DIR` 环境变量、默认的 `%LOCALAPPDATA%\AppShelf`。例如：

```powershell
$env:APPSHELF_DATA_DIR = "D:\AppShelfData"
python server.py
```

目录内的主要文件：

| 文件 | 用途 |
|---|---|
| `apps.json` | 当前清单 |
| `apps.json.bak` | 上一次写入前的有效清单；只保留一份备份 |
| `apps.lock` | 多个 AppShelf 进程协调读写使用的锁文件 |
| `usage.sqlite3` | 独立的前台使用时间历史，SQLite 数据库 |
| `usage.sqlite3-wal`、`usage.sqlite3-shm` | SQLite 运行期间可能产生的事务辅助文件 |
| `usage.collector.lock` | 确保同一数据目录只有一个进程采集前台活动 |
| `preferences.sqlite3` | 100 条语录的跨启动轮换顺序，不改变清单和时长 |
| `usage-icons/` | 实际使用过的软件图标缓存 |
| `background.json` | 后台开关与启动代次，停用不删除历史 |
| `background-status.json` | 后台心跳和采集状态，界面读取以区分记录、闲置、锁屏和异常 |
| `background.*.lock` | 后台设置与独立进程的互斥锁 |
| `background.log` | 后台错误日志，按大小轮换 |

读取、修改、备份和替换都通过同一存储入口。进程内锁和文件锁覆盖整个读改写过程；写入先生成并刷新临时文件，再替换当前文件。编辑提交还携带清单版本，版本已变化时返回冲突提示，防止旧窗口静默覆盖新数据。

遇到版本冲突时，当前编辑窗口会保留输入，但此次修改尚未保存。先复制需要保留的改动，再关闭编辑窗口、刷新清单并重新编辑。

如果清单损坏，程序会报告错误并保留原文件，不会自动重建为空清单。恢复前先关闭所有使用该目录的 AppShelf 实例，并保留损坏文件副本，再用核对过的 `apps.json.bak` 恢复。备份不替代长期数据备份。

`apps.json.bak` 只备份应用清单。备份使用历史时，先关闭后台记录开关，再关闭所有使用该目录的 AppShelf 窗口，备份 `usage.sqlite3` 及仍然存在的同名 SQLite 辅助文件；也可使用 SQLite 在线备份。统计数据库故障会单独报告，不影响应用目录启动，也不会自动清空历史。

## 使用方式

- **首页**：款数、分类数和今日前台时长直接展示在两个入口卡中，下方最多显示 4 个今日常用应用。首页和本页顶部导航统一采用最高 1440px 的宽度与自适应边距，减少大屏两侧空白。较高宽屏下，入口和常用卡片适度增加内距与高度；小窗口保持紧凑，手机仍自动切换单列。入口有鼠标悬停与键盘焦点反馈，完整路径留在悬停提示中。目录与统计独立读取，一个来源失败不会挡住另一个；没有记录时显示空态。首页只读，不触发扫描或改写清单；首页和目录页不再显示底部技术说明。
- **古诗拾句**：问候语下方内置 1000 条完整古诗联句，显示朝代、作者和篇名，离线可用。每次启动轮换，1000 条用完前不重复；刷新概览和统计时保持本句。与使用时间页的 100 条原创语录独立轮换。内容来源与整理规则见 `docs/poetry.md`。
- **浏览与筛选**：分类侧栏按 8 个大类整理 21 个子类；全局搜索固定在顶部，搜索会进入全部应用结果并取消位置筛选。「安装位置」下拉框筛选盘符和网络路径。「全部应用」切换到总目录，「所有位置」只取消位置筛选。
- **返回导航**：从目录进入详情后，返回会恢复关键词、分类、安装位置、目录滚动位置与相关条目的展开状态。正常进入的详情优先使用浏览器后退；直接打开详情链接时，使用经过检查的站内返回地址或全部应用作为后备入口。
- **分类切换**：同一目录界面内更新右侧结果，不重载页面或左侧分类。分类展开与滚动位置保留，浏览器前进、后退同样可用。
- **相关条目**：不再显示容易被误解为副本数量的「N 份」徽标。同一相关组可展开「相关条目与位置」，查看名称、版本、位数和路径；例如 QQ 与邮件插件可以有关联，但不代表装了多份 QQ。历史清单中误归入 Git 组的 Logitech 条目仅在展示时排除关联，不修改原数据。
- **真实图标**：优先使用随程序附带的本机程序图标及官网图标缓存，离线也可显示；没有可用图标的条目使用中性应用图形，不以首字母冒充 Logo。缓存来源记录在 `assets/icon-sources.json` 和 `assets/web-icon-sources.json`。
- **编辑**：修改名称、分类、介绍、域名、路径和相关分组；清空分组会移除原分组。来源和占用大小始终只读；普通应用的安装日期可编辑，系统自带应用的日期显示已有记录并保持只读，没有可靠日期时显示未知。
- **多个路径**：编辑器一行填写一个路径。已有路径暂时不可用时，仍可修改其他信息；新增或更改的磁盘路径在本地模式下需要通过存在性检查。
- **定位**：点击路径在 Windows 资源管理器定位。编辑器不提供占用测量或改写入口；自动扫描不会递归计算目录大小。
- **当前目录**：隐藏未检测到、已卸载、确认不存在及同一次安装的重复记录；底层 ID、介绍与路径继续保留。不同安装路径、不同明确版本或架构的真实副本仍分开显示。重新扫描发现软件存在后可恢复，目录数量、分类、搜索和首页遵循相同显示规则。
- **扫描确认**：「新发现」可确认收录，明确不存在的新软件不加入清单。无法访问的路径或断开的磁盘只代表未知，不认定为卸载；无独立安装位置的系统组件按已有证据判断。
- **更新提示**：后台扫描或其他窗口修改清单后，页面提示刷新，不会直接替换正在编辑的内容。

扫描使用注册表键作为安装身份，并匹配完整名称，不再用子串或去掉版本号的词干合并软件。相同名称的不同安装位置可以分别保留，也不再限制每次只发现 30 条。

对于已绑定注册表身份的应用，只有注册表记录消失、已知本地路径均不存在且所在磁盘可用，才确认卸载。断开的磁盘、网络共享、无法访问的路径及便携软件缺失只能作为不确定证据。注册表记录或有效路径重新出现后，可以恢复原条目。注册表读取不完整时，整次扫描失败并保留原清单。

## 使用时间

从顶部「使用时间」进入 `usage.html`，用精简统计条查看累计前台时间、最常使用的应用和应用数，下方按日、周、月展示时间分布图及应用排行。页面只展示真实记录，没有使用记录时显示空态，不生成演示时长。

时间分布默认使用折线图，可直接切换柱状图。日、周、月共用同一组真实数据，切换图形仅重绘，不再次请求或修改记录。折线直连已发生时段的真实读数，保留零值；未来时段只有坐标与淡背景，不虚构为下降至零。图表类型保存在页面地址中，从详情返回时一并恢复。

页面使用已确认的 100 条原创时间语录。每次启动 AppShelf 随机选一句，100 条用完前不重复；新一轮首句也避开上次。刷新统计、切换日周月、浏览其他页面或跨过午夜均保持本次启动的语录。轮换顺序单独保存在用户目录的 `preferences.sqlite3`，不依赖浏览器端口或清除浏览记录。

应用排行及「最常用」的软件名称前显示图标，优先从实际记录的本机可执行文件提取，没有内嵌图标的打包应用读取其安装包中的图标，不启动该软件。PNG 缓存在用户目录 `usage-icons`，程序暂时不存在时可继续使用已缓存图标；无法提取时使用目录中的缓存图标，最后显示统一占位图。首页的今日常用同样使用该规则。

默认开启独立后台记录：关闭 AppShelf 窗口后，隐藏的计时进程继续运行；当前用户登录 Windows 后自动启动计时，无需打开主界面。使用时间页底部的「后台记录与登录自启」开关可同时停用这两项，停用后只在窗口打开期间记录。启动失败时界面显示实际错误，窗口可继续临时记录；不假报自启成功。记录约每秒采样一次，按亮屏时的前台停留计时，阅读、观看或等待回复不会因无键鼠输入而停止。熄屏、锁屏、睡眠、长采样间隔和采样失败会打断连续记录。启动前和采集停止期间不补算历史。

后台进程只采集使用时间，不打开窗口、不启动 HTTP 服务、不扫描或修改应用目录、不轮换启动语录。登录启动项仅写入当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，按数据目录区分；停用时只移除对应项。移动或删除程序前应先停用后台记录，再从新位置重新打开并启用。

同一时刻只累计一个前台应用。同一可执行文件的多个窗口、多个进程只计一份。WindowsApps 应用更新后带版本号的路径会变化；同安装根目录、包名、架构、资源、发布者及相对程序路径，仅版本不同的记录会在首页和排行中合并时长，详情、图标和旧链接同样适用。不同安装位置、不同发布者或不同程序继续分开。合并仅发生在读取时，不改写或删除原始使用区间。只保存可执行文件路径和时间区间，不保存窗口标题、键盘内容或鼠标内容。多个 AppShelf 实例使用同一数据目录时，仅一个实例采集，其余实例读取相同历史。

点击排行、最常用或首页常用的应用可打开详情。已收录的软件进入目录详情；未收录的软件展示真实程序路径和可读取的版本信息，不自动生成目录记录。返回后保留统计周期、日期和滚动位置。清单中的共享工作目录不会用于认领深层无关程序；同产品同路径的扫描重复项只用于选择合适详情入口，底层记录均保留。

统计采用电脑本机时区：日视图按小时汇总，周视图从周一开始，月视图按自然月汇总。时长保留到整秒，不再舍去分钟之后的余秒；首页与统计页每约 5 秒安静刷新，切换周期和手动刷新会立即读取。刷新保留图表和排行的焦点、滚动及正在编辑的日期，不在浏览器中推算未采集时长。

图表直接标注非零时长，统一坐标单位，并显示真实高峰时段。鼠标悬停或键盘聚焦柱形可查看完整时间段和时长；当前时段强调，尚未发生的时段淡化。小窗口下完整时间轴可横向滚动，刷新保留滚动和键盘焦点。目录隐藏记录不会删除过去的使用时间。

排行中的时长数字和色条共同按本列表的使用时长顺序映射深浅：时间越多越深，越少越浅，相同时长颜色相同，不同时长均匀分布在米金、暖橙到深陶红的连续色阶上，避免几秒与几小时并存时颜色全部挤在两端。色阶的亮度依次降低，数字使用同一暖色系的较深颜色以保持清晰。最长项占满色条，其余按相对最长项的时长调整长度，并保留 6% 的可见起点，避免短时长消失到不足一像素；正时长越长，色条始终越长，准确时长见右侧数字。排行提示中说明最小可见刻度，小屏也显示色条。5 秒更新只调整原节点的文字、长度和颜色，保持焦点，减少动态效果的系统设置会关闭过渡。

日、周、月共用一个只读接口：

```text
GET /api/usage?period=day&date=2026-10-15
GET /api/usage?period=week&date=2026-10-15
GET /api/usage?period=month&date=2026-10-15
```

`date` 是所选周期内的一天，省略时使用本机今天；`period` 默认 `day`。返回 `start`、`end`、`buckets`、`apps`、`totalSeconds` 和采集 `status`，时长单位为秒，`end` 为不包含的结束边界。接口沿用本机来源限制；无效参数返回 400，统计数据不可用时返回 503。

AppShelf 自身图标已统一为陶土红、米白书架：程序 EXE、窗口、导航品牌与五页 favicon 共用相同设计。素材及生成说明见 [图标素材](docs/branding.md)。

## 数据模型

清单仍是 JSON 数组。路径的规范结构是 `paths`，每项分别保存实际路径、类型和说明；旧的 `path` 展示字符串继续兼容。

```json
{
  "id": "example-app",
  "name": "Example Editor",
  "category": "dev-ide",
  "description": "代码编辑器",
  "paths": [
    {"path": "D:\\Apps\\Example", "kind": "directory", "note": "主程序"}
  ],
  "path": "D:\\Apps\\Example（主程序）",
  "size": null,
  "source": "unknown",
  "installDate": null,
  "site": "example.com"
}
```

`kind` 支持 `directory`、`file`、`unknown`。旧清单在读取和显式导入时转换为该结构；实际保存时保留兼容的 `path` 字段。扫描还可维护 `registryId`、`version`、`status`，不会用注册表名称覆盖用户整理的名称和介绍。

│   ├── usage.py            前台采样、闲置判断、SQLite 使用历史和周期汇总
│   ├── storage.py          JSON 事务、备份、文件锁、版本冲突

## 静态预览

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000/home.html> 查看首页，或打开 <http://127.0.0.1:8000/index.html> 直接进入目录。此时浏览的是仓库里的旧快照；编辑仅保存在当前浏览器的 `localStorage` 草稿中，不会修改 JSON 文件，也不会进入本地服务的用户清单。清理站点数据可能丢失草稿。

静态模式允许填写路径草稿，但无法验证本机目录、测量大小、定位文件或扫描注册表。请通过 HTTP 访问页面，不要直接双击 HTML 文件。

静态模式的首页保留目录概览与入口，使用时间显示需要本地记录的说明；使用时间页也不采集活动、不读取历史、不填充模拟数据。编辑草稿同样遵守来源、占用及系统日期只读规则。

## 旧脚本与当前限制

`scripts/scan.ps1`、`collect_dates.ps1`、`augment.py`、`group.py`、`size.py` 保留为旧版离线整理工具。其中部分脚本会写仓库内的 `data/apps.json`，不会读取当前用户数据目录的配置，也不经过实时存储事务。它们不是运行中的清单管理接口；需要使用其结果时，应先离线检查，再显式导入空目录。

- 相关分组表示条目之间的关联，不代表相同应用、副本数量或相同安装；展开关联不会合并底层记录。旧快照的历史分组不会自动重算。
- 记录大小可能包含相同目录或父子目录，合计值不能视为磁盘真实占用；扫描优先补充注册表报告的估计占用，可执行文件记录可提供文件大小，没有可靠数据时留空。
- 已知产品可自动补充用途、分类和官网；其他应用仍需人工整理。安装日期只补充有来源的有效日历日期，不用文件创建时间推算系统组件的安装日期。
- 已缓存图标可离线使用；未缓存的官网图标依赖外部服务，加载失败时使用中性图形占位。
- 应用清单采用 JSON，使用时间历史采用独立 SQLite；暂不提供清单完整历史版本、云同步或跨设备合并。
